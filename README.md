# ANALOG-CLOCK

## About The Project

A simple analog clock made with HTML, CSS and JavaScript. The clock displays the current time and updates every second.

It follows the LinkedIn Learning course [JavaScript Essential Training](https://www.linkedin.com/learning/javascript-essential-training). The specific content related to the analog clock seems to not be available anymore on LinkedIn Learning.

### Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

### Installation

Launch the project in your browser through the `index.html` file.
